# TEAM-30 전체 필터 검토와 분리 비교

운영/연구 전체 필터를 정적으로 목록화하고, 그중 공개 일봉으로 검증 가능한8개 설정을 동일4ETF/회복형/원장에서48회 비교했다. 모든 필터의 수익 효과를 실증한 것은 아니다. 신규7설정과기존기준 모두 기존 과거 통합승인 미달이며 신규승인0이다. 현금 한도·최종10% 영구차단·기존승인기준·운영은 변경하지 않았다.

## 판단

1. 개별SMA200 추세필터를제거하면 장기10%차단이발생하고4,528거래일이차단상태가됐다. 최근2년수익만보면비슷하지만장기보호효과를잃었다. 현재근거로제거할이유가없다.
2. 시장상승조건이좋을때만새진입하는필터는장기낙폭7.80→7.47%로줄었지만연환산3.37→3.24%로낮아졌다. 상승장을기다리는것만으로목표수익을해결하지못했다. 기존보유는개별조건으로관리하며이필터는시장하락시전부현금화하는규칙은아니다.
3. 매일신규진입은2026누적-3.63→-2.46%로좋아졌으나장기수익은3.37→3.20%,거래840→1,327건이었다. 한기간개선만으로채택하지않는다.
4. 정상매도를월별로늦추면장기수익은3.50%로조금높아졌지만올해누적-5.00%,장기낙폭8.25%로악화했다. 무조건오래보유하면좋다는근거는아니다.
5. 6%임시대기는장기낙폭7.80→7.12%와연환산3.37→3.27%의교환관계였다. 위험완화가설의후속후보일수있으나연10%통과전략은아니다. 올해는대기20일에도누적수익-3.65%로기준보다낫지않았다.
6. 투자상한40%는낙폭5.68%로줄었지만장기연환산2.31%,최근2년5.62%로목표미달이다.10%손실차단과40%투자비중은서로다른조건이다.

고변동성진입제한은이번자료에서작은차이만보였다. 필터를조금씩바꿔고른결과이므로미래개선의통계적증거라고부르지않는다. 좋은조건만사후에조합해새승인후보를만들지않았다.

## 일시대기 정책의 정확한 의미

고점대비6%도달시매수목표0으로다음시가정리하고,최소20관찰거래일+SPY종가>SMA200 및SMA200상승조건5일연속일때재개한다. 기존고점을그대로유지하고최종10%영구차단을최우선적용한다. 재개직후같은손실로반복중단하지않도록고점대비낙폭3%미만회복때만6%기능을재무장한다. 이항목은복합휴식정책이며각숫자별효과를분리검증한것은아니다. 실제10%차단이발생했다면시장상승조건만으로재개하지않는다.

## 전체 검토와 실증 범위의 구분

기존Java장중TREND,승인연구연결,TEAM23~29연구는서로다른필터다. 정적목록은 프론트문서 `docs/ai-team/tasks/TEAM-30-FILTERS.md`에있다. 과거거래대금순위/당시전망PER·ROE/RVOL/호가/ATR체결등은자료부족으로같은장기실증을하지못했다. 이번48회는TEAM24분산추세일봉의선택·진입·청산·비중·대기정책비교다. 장중필터전체를검증한것으로표현하지않는다.

매일목표수량재조정비용과SPY변동성을모든자산위험대리로쓰는문제도정적가설로남는다. 다른연구의종목선택효과와매매빈도효과가섞일수있으며이번결과만으로원인전체를확정하지않는다.

## 제한·재현

일봉다음시가가상체결,수수료/슬리피지,정수수량,현금99%,매도대금다음거래일,최종차단을동일적용했다. 실제호가/부분체결/세금/환율/정규장감시와는차이가있고10%는손실상한보장이아니다. 이미본역사자료로독립새표본이아니며전진관찰0일·0체결이다. 매매승인이나실계좌시작은하지않았다.

diagnostics의market_gate_closed_days/vol_gate_closed_days는시장조건불충족일수이며실제매수신호가차단된횟수와다르다. 조건별거절횟수나거래안한기회손익으로과장하지않는다.

```powershell
python -I tools/team30_research.py freeze --data .research-runtime/public-smoke/market/20261121T163923Z-ffb6ab57 --output tools/team30_results/new-experiment
python -I tools/team30_research.py run --output tools/team30_results/new-experiment
python -m unittest discover -s tools -p "team30*test.py" -v
```

기존출력은덮어쓰지않는다. 모든원장 runs/, 요약 summary.json, 판정 judgments.json, 사전선언 manifest.json에보존한다.
