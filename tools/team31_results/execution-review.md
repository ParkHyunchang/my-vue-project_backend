# TEAM31 실행 적합성: balanced_trend:recovery_vol

이 문서는 실계좌 승인서가 아니다. 현행 Java 실행 경로와 합성 계좌를 검증한다. 실제 주문·운영 설정·DB·키에 접근하지 않았다. 신규 전략/운영 코드를 변경하지 않았다.

## 계좌 정보와 가정

- 사용자 확인: 기존 JEPQ 3주, 주문 가능 달러 현금 $35.48. 실제 평가액·위험 관리 고점 미확인.
- 합성 가격: SPY $600, QQQ $500, GLD $250, IEF $100, JEPQ $60. 시세가 아니며 스프레드 0이라는 테스트 가정이다.
- 합성 계좌: 위 JEPQ 3주($180) + 현금 $0/$35.48/$100/$500/$1,000/$5,000/$10,000, 평가액=고점. 모든 ETF 추세 적격, SPY 변동성10%, 따라서 목표 총비중80%라는 유리한 경우다.
- 정수 1주 단위, 주문 가능 현금99% 내에서 매수, 가정 매수 비용12.5bps. 실제 브로커 비용/환전/세금/슬리피지는 검증하지 않았다.
- `execution-sizing.json`은 `UsOperationalCandidateTest`가 실제 planner 호출 결과에서 생성한다. 수익률 백테스트가 아니다.

## 운용에 영향을 주는 제약

2026-11-23 격리 실행에서 신규 `UsOperationalCandidateTest` 2개 모두 통과(실패/오류/건너뜀 0). 실제 planner가 생성한 결과는 다음과 같다. 모든 행에서 기존 JEPQ 3주 매도가 먼저 계획되며, 매도 대금은 아래 매수 예산에 포함되지 않는다.

현재 사용자 현금에 가까운 계좌는 이 가격 가정에서 매수 가능한 목표 수량이 0이므로 **현행 4ETF 운용 후보에 크기 부적합**이다. 목표비중80%가 실제80% 투자라는 의미는 아니다. 실제 JEPQ 평가액·고점은 읽지 않았으므로 이것은 실계좌 평가 결과가 아니다.

1. **기존 JEPQ 3주 전량 매도 대상이다.** 이 전략은 SPY/QQQ/GLD/IEF 외 종목 목표 수량을 0으로 만든다. 기존 보유를 관리한다는 의미가 JEPQ를 계속 보유하며 별도로 매수한다는 뜻은 아니다. 실제 전략 승인 전에 이 교체 내용을 사용자에게 보여야 한다.
2. **소액 계좌는 전략 의도와 실제 비중이 크게 달라질 수 있다.** 최대 비중80%에서도 SPY32%, QQQ/GLD/IEF 각16%이고, 부족한 자산의 비중을 다른 자산에 재분배하지 않는다. 합성 가격 기준 ETF별 1주 목표가 생기는 최소 전체 평가액은 SPY $1,877.34375, QQQ $3,128.90625, GLD $1,564.453125, IEF $625.78125다. 네 자산 모두 목표 1주 이상인 최소 평가액은 $3,128.90625이나, 이는 실행 가능한 권장 최소 자금이 아니다. 별도 현금 한도·기존 종목·실제 가격·변동성/손실 상태에 따라 매수 불가능할 수 있다.
3. **매도 접수/체결 예상 대금으로 같은 배치에서 매수하지 않는다.** 현금0이면 기존 보유 매도 주문만 가능하다. 실제 주문 가능 현금이 갱신된 다음 평가가 필요하다.
4. **매도대금 지연의 기회비용이 있다.** FULL에서 못 산 수량은 다음 일봉의 FUND 한 번만 보충한다. FUND 날에도 현금이 없으면 이후 들어온 현금으로 일반 HOLD 날 재시도하지 않는다. 신규 테스트는 최초 FULL→현금0 FUND→현금도착 HOLD→다음 달 FULL의 실제 계획을 검증한다. 다음 달 이전 다른 위험/추세 변화로 매도가 생길 수는 있으나, 추가 매수를 보장하지 않는다. 현재 코드는 의도된 재시도 제한을 유지했으며, 관찰 때 현금도착일과 실제 투자비중을 기록해야 한다.
5. **10% 손실 차단은 계좌 서비스의 책임이다.** 순수 planner만 호출한 합성 테스트로 계좌 차단을 입증하지 않는다. 기존 실제 서비스(mock broker) 통합 검사의 `hardRiskLatchStopsAllStrategyBuysBeforeClaim`을 함께 실행한다. 갭/미체결로 실제 손실이 정확히10% 이내라는 보장은 없다.
