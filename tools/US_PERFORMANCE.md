# 미국 전략 오프라인 성과 평가

`us_performance.py`는 Python 3 표준 라이브러리만 쓰는 CSV 평가기다. 서버·DB·계좌·브로커 API를 사용하지 않으며 주문 기능이 없다. 기존 TREND 전략을 재생하는 백테스트나 가상 주문 엔진은 아니다. **실제 자료가 제공되지 않았으므로 현재 전략의 S&P 500 초과수익은 미검증이다.**

## 실행

백엔드 저장소에서:

```powershell
python -B -m unittest discover -s tools/tests -v
python -B tools/us_performance.py tools/fixtures/us-performance-synthetic.csv --kind synthetic --holdout-start 2025-01-02
python -B tools/us_performance.py <평가자료.csv> --kind historical --holdout-start 2025-01-02 --output <결과.json>
```

종료코드는 제공 자료의 모든 기준 충족 시 0, 미충족·합성자료·입력 오류 시 2다. 합성 예제의 종료코드 2는 의도한 결과다. 성공 문구도 `CRITERIA_MET_ON_SUPPLIED_DATA`로 한정되며 미래 수익이나 자료의 신뢰성을 보장하지 않는다. `--kind`는 사용자의 자료 분류 선언이며 출처 인증이 아니다.

## CSV 계약

| 열 | 의미 |
|---|---|
| date | 미국 시장 기준 평가일 YYYY-MM-DD, 중복 없이 오름차순 |
| equity_usd | 같은 평가시점 전체 계좌의 USD 순자산: 현금+모든 보유 시가+미수/미지급 반영. 수수료·거래비용·배당을 이미 반영한 금액 |
| external_flow_usd | 해당 기간 말 외부 순입금(입금 양수, 출금 음수). 매수/매도·배당은 외부 입출금이 아님 |
| fees_usd | 해당 기간 이미 순자산에서 차감된 비용의 감사용 합계. 평가기가 재차 차감하지 않음 |
| sp500_total_return_index | 같은 날짜/시점의 S&P 500 배당 재투자 총수익 지수. 가격지수나 단순 SPY 종가를 넣으면 공정 비교가 아님 |

첫 행은 기준시점이며 그 행의 flow/fees는 평가 구간 합계에서 제외한다. 각 다음 행은 이전 평가 이후 기간을 나타낸다. 기간말 입출금 가정으로 일별 수익은 `(현재 순자산 - 외부 순입금) / 이전 순자산 - 1`이다. 장중 입출금은 입출금 전후 평가시점으로 나눈 입력 자료가 필요하며 이 일별 CSV 모델로 정확히 처리할 수 없다. 원화환산 성과와 혼합하지 않는다.

일별 수익을 연결한 TWR, 실제 경과일 기준 CAGR(365.25일), 연결 NAV의 고점 대비 최대낙폭, 동일 기간 배당포함 벤치마크 수익 및 초과수익(%p)을 출력한다. 음수/0 순자산, NaN/Infinity, 음수 비용, 누락 지수, 역순/중복 날짜는 거부한다. 짧은 기간 CAGR은 기계적 연율화이며 장기 수익 예측이 아니다.

## 평가 기준과 한계

- 별도로 고정한 holdout 구간에서 비용 반영 TWR이 S&P 500 총수익보다 높고, 관측 최대낙폭이 10% 이하여야 한다.
- 최소 평가기간은 실행 정책으로 기본 365일이며 `--min-days`로 명시 변경할 수 있다. 365일은 통계적 충분성이나 최적 기준을 입증한 값이 아니다.
- holdout은 정확히 일치하는 기준일과 그 이후 자료를 사용한다. 그 날짜 전 자료로만 전략/설정을 선정해야 한다. 도구는 실제 설정 선정 이력을 확인할 수 없다.
- 합성자료는 계산 검증 전용으로, 높은 수익률이 나와도 항상 `UNVERIFIED_SYNTHETIC_DATA`다. 실제자료에 holdout이 없거나 기준을 충족하지 못하면 `CRITERIA_NOT_MET`다.
- 누락 거래일, 생존편향, 미래정보 사용, 자료 출처, 실제 비용 반영 여부는 자동으로 판별하지 못한다. 매 거래일을 포함한 동일 시점 자료를 공급하고 별도 검토해야 한다. 관측일 사이의 낙폭과 장중·갭 손실은 계산에 드러나지 않을 수 있다.
- 전체 계좌 10%는 위험 통제 발동 기준이다. 이 평가기는 청산이나 손실 제한을 실행하지 않으며 실제 손실 10% 상한을 보장하지 않는다.

## 기존 TREND 검증의 다음 단계

현재 신호는 `KiwoomUsTechnicalSignalService.calculate`에서 완료된 51거래일 이상 일봉, SPY/QQQ, 해당 시점 호가를 입력받아 계산한다. 재생 검증은 이 순수 계산을 같은 패키지의 테스트 어댑터에서 재사용할 수 있다. 당시 사용 가능했던 구성종목·재무자료·거래량순위·호가/스프레드가 필요하므로 현재 구성종목이나 일봉 종가만으로 실행 전략을 동일하게 재현했다고 주장하면 안 된다.

1. 당시 구성종목/상장폐지 포함 종목군과 조정 일봉, 당시 공개 재무정보, 시각별 순위·호가를 버전 고정한다. 미래 봉은 signal session 이전으로 잘라 넣는다.
2. 신호 생성 다음 체결 가능 시점에 비용·슬리피지·부분체결·주문거절·현금예약을 반영한다. 같은 일봉에서 고가/저가 순서를 임의로 유리하게 선택하지 않는다.
3. 기존 보유도 초기 계좌에 포함하고 입출금·수수료·배당·전체보유 평가 원장을 남긴다. 입출금 보정 고점/10% 통제, 중단/재시작도 재생한다.
4. 튜닝 구간과 미사용 holdout/워크포워드 구간을 고정하고, 평가기 CSV를 매 거래일 출력한다. 체결 가정과 데이터 누락을 결과 옆에 기록한다.
5. 별도 가상 주문 실행에서 동일 원장을 생성해 비교한다. OBSERVE는 실제 LEGACY 주문을 실행하므로 모의매매로 사용하지 않는다.

실제 시점별 시장자료·원장이 없는 이번 합성 테스트는 위 단계의 전략 성과나 실거래 안전성을 검증하지 않는다.
