# 개별주식·장중 검증의 자료 요구사항

2026-11-23 확인. 계정·유료자료가 없는 현재는 공개 가격 표본을 확보해 탐색한다. 탐색 완료와 기존 승인 기준을 충족하는 자료 확보는 별개다. 운영·구독·구매·가입은 실행하지 않았다.

| 자료 | 사용 목적 | 현재 공개 표본의 한계 |
|---|---|---|
| 개별주식 원본 일봉·배당·분할 | 역사 명목가격·보유수량·현금 복원 | 현재 존속8개 표본, 분사/합병/상장폐지·역사모집단 미해결 |
| UTC시각 포함5분 OHLCV | 개장30분 돌파·반등, 다음봉 체결 탐색 | 최근기간만, 장기2008~ 검증 불가 |
| 약2년1시간 OHLCV | 추가 탐색용 보관 | 5분봉 대용이 아니며 같은 전략을 재현하지 못함 |
| 역사 체결·최우선매수/매도호가 또는NBBO | 스프레드·지연·실행가능 가격 모형 | 공개봉으로 복원 불가, 아직 미확보 |
| 거래정지·시장상태·정정/취소·세션 달력 | 잘못된 체결/누락봉 탐지 | 일반 OHLCV에 충분하지 않음 |
| 역사 구성종목·상장폐지·종목식별자·기업행사 | 생존편향·종목코드 변경과 현금권리 처리 | 현재 유명주 목록으로 대체 불가 |

## 추가 확보 경로

- [Alpaca 공식 FAQ](https://docs.alpaca.markets/us/docs/market-data-faq): API 인증이 필요하다. 최근15분 제한과 과거SIP 조회를 구분하며 무료실시간IEX가 전체 시장과 같지는 않다. 별도 데이터 계정에서 실제 허용 종목/피드/시작일을 확인해야 한다. 계정만 만들면2008부터 모든 자료를 받을 수 있다고 가정하지 않는다.
- [NYSE Daily TAQ 사양](https://www.nyse.com/publicdocs/nyse/data/Daily_TAQ_Client_Spec_v4.3.pdf):1993부터의 역사 체결·호가를 설명하며 기간별 라이선스가 필요하다. 기존2008장기 기준을 유지할 때 검토할 수 있는 공급원이다. 최소한8개 표본과 비교지수,2008~현재의 필요한 세션·가격·거래상태 범위를 지정해 견적/접근권을 확인해야 한다.
- [Databento 가격·범위](https://databento.com/pricing/): 봉·체결·호가·기업행사 등 제품과 사용량/구독 방식이 있다. 데이터셋마다 시작일·거래소 커버리지가 다르므로2008부터의 충분성을 확인해야 한다. 무료 크레딧으로 전체 자료가 확보된다고 판단하지 않는다.
- [Norgate 자료 구성](https://norgatedata.com/data-content-tables.php): 상장폐지 및 역사 지수 구성종목을 포함하는 패키지가 있다. 일봉 모집단/종목 이력 검토용이며 장중호가 공급원의 대체물이 아니다. 역사 구성종목은 해당 구독 수준과 지원 형식을 확인해야 한다.

공급원 비교는 실제 견적이나 구매 권고가 아니다. 장기 호가 전체를 무작정 내려받기 전에 한 종목·한 거래일 샘플로 시각·기업행사·피드·세션·권리조건을 확인하고 이후 필요한 범위를 산정한다. API키는 채팅에 보내거나 Git에 저장하지 않는다. 실제 계좌 주문 권한은 데이터 확보에 필요하지 않다.

## 승인 전 누락 자료 처리

현재 기준인 최근2년/올해/2008연속×두비용의 전체평가를 지원하지 못하면 `historicalPassed=false`로 남긴다. 짧은 장중 수익을 연환산해10% 목표 충족으로 사용하지 않는다. 새 전략의 등록 이후60신규거래일·20체결 관찰도 과거 데이터로 채우지 않는다. 자료가 충분해져도 별도 실제 체결 모형 검증과 사용자 승인이 필요하다.
