# TEAM-29 개별주식·장중 탐색 결과

공개 자료를 새로 확보하고 개별주식 일봉24회·5분 장중4회 총28회 탐색을 실행했다. 새 승인 후보는0개다. 필요한 자료 일부는 확보했지만 장기호가·상장폐지 포함 역사모집단이 없어 전체 승인 검증에 필요한 자료 확보가 끝난 것은 아니다. 기준을 낮추거나 운영에 적용하지 않았다.

## 확보 자료

| 자료 | 실제 확보 | 상태/용도 |
|---|---|---|
| 개별8주+SPY 일봉 | 2006-01-03~2026-11-20,47,295행 | 원본·CSV·통합19파일 검증 |
| 개별8주+SPY 5분봉 | 2026-09-25~11-20,28,611행 | 관측41일 중40완전 공통세션 사용 |
| 개별8주+SPY 시간봉 | 2024-11-25~2026-11-20,31,248행 | 499일 중493개 완전세션, 확보·정규화 검증만 수행 |

대상은 AAPL/MSFT/AMZN/GOOGL/NVDA/JPM/XOM/PG와SPY다. 장기 일봉은 GOOGL2014 기업행사(1998:1000)와NVDA2007 비정수분할(3:2)을 현재 원장으로 처리하지 못해 성과 실행 전에 두 종목을 제외했다. 따라서 일봉 매매 대상은6주, 최근 장중은8주다. 제외 원본을 지우거나 해당 이력을 일반 분할로 강제 처리하지 않았다.

5분봉은2026-11-05 모든종목59봉으로19봉이 부족해 그날을 제외했다. 전체 세션이 통째로 누락된 날은 없지만 제외일의 실제 거래 손익은 미검증이며, 미래에 누락될 날을 미리 알고 거래하지 않을 수 있다는 뜻은 아니다. 시간봉 초기 정규화는 단축장 경계의 시각 때문에 실패했다. 실패 원문을 보존하고60m-normalized에 별도 정규화했으며, 단축장5일과11월5일 누락을 표시했다. 시간봉으로5분 전략을 대신 검증하지 않았다.

## 장중 전략 — 실제40거래일 표본

개장30분 돌파와 개장 이후 눌림반등을 비교했다.8종목 중 신호강도 상위1개·하루1회 매수·최대80%·다음5분봉시가·15:45이후신규매수금지·15:55시가청산이다. 종가에서 매입가격대비-2%/+3%면 다음봉에 청산한다. 매도대금은 다음관찰세션에 결제하고 계좌 고점과10%차단은 날짜 변경으로 초기화하지 않는다. 봉저가에서 위험차단을 관측해도 해당저가에 청산된 것으로 꾸미지 않고 다음봉시가로 청산한다.

추가로 필요한 장기 거래·호가·거래정지·역사구성종목·상장폐지·기업행사와 공급원은 [DATA_REQUIREMENTS.md](../DATA_REQUIREMENTS.md)에 정리했다. 별도 계정 생성·라이선스·유료구매를 실행하지 않았다.
